# vaab-site

Landing page and browser playground for [Vaab](https://github.com/vaab-lang/vaab) — a strictly typed, plain-English programming language.

**One command serves everything:** the React frontend, the `/health` API, and the interactive playground (`POST /api/run`).

## Quick start

Requires a local [Vaab](https://github.com/vaab-lang/vaab) build with static-file support (`reply file`, catch-all routes).

```sh
# 1. Build the frontend
cd web && npm install && npm run build && cd ..

# 2. Start the site (from this directory)
vaab serve main.vaab
# → http://127.0.0.1:8787
```

Or via Cargo from the vaab checkout:

```sh
cargo run --bin vaab -- serve /path/to/vaab-site/main.vaab
```

## What's inside

| Path | Purpose |
|------|---------|
| `main.vaab` | Unified server — static files + health check |
| `riffs/express/` | Sinatra-style riff: `for_path`, `mime_for` helpers |
| `web/` | React + Vite landing page with CodeMirror playground |
| `web/dist/` | Production build (generated by `npm run build`) |

## Architecture

```
Browser
   │
   ├─ GET /*          → main.vaab route → reply file (express-style static)
   ├─ GET /health     → Vaab JSON route
   └─ POST /api/run   → vaab-server playground (embedded VM)
```

The playground runs code through the real Vaab parser, type checker, and VM — the same pipeline as `vaab run`.

## Express riff

The `express` riff (`riffs/express/`) provides helpers inspired by Sinatra/Express:

- `express.for_path(root, requested)` — resolve a safe path under a static root
- `express.mime_for(path)` — guess a content type from a file extension

`main.vaab` inlines the path logic in the static route (riff function calls inside route handlers are being fixed upstream). The riff is available for other Vaab apps via:

```
need express from ./riffs/express
```

## Development

```sh
# Terminal 1 — build + serve
cd web && npm run build && cd ..
vaab serve main.vaab

# Or iterate on frontend separately:
cd web && npm run dev   # Vite dev server (proxy /api to :8787 if runner is up)
```
